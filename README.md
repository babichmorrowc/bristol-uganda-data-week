# Bristol–Uganda Collaborative Training Visit on Health Data Science

Training materials for the 2026 Bristol–Uganda Collaborative Training Visit on Health Data Science:

## Technical trainings

### Training #1: Introduction to Git and GitHub

All materials for this training are available in the folder [`intro-to-git-github`](https://github.com/babichmorrowc/bristol-uganda-data-week/tree/main/intro-to-git-github):

+ [Slides presented](https://github.com/babichmorrowc/bristol-uganda-data-week/blob/main/intro-to-git-github/Introduction%20to%20Git%20%26%20GitHub.pdf), including links to external materials
+ 5 numbered files containing instructions to the different exercises
+ A folder called `branching-practice` where the files for the branching exercise live

### Training #2: Introduction to R

All materials for this training are available in the folder [`intro-to-r`](https://github.com/babichmorrowc/bristol-uganda-data-week/tree/main/intro-to-r):

+ [`tutorials`](https://github.com/babichmorrowc/bristol-uganda-data-week/tree/main/intro-to-r/tutorials): Folder containing the original tutorial files. Please do not edit these files! You can make copies of these files with your names in the file name to edit.
+ [`tutorial_solutions`](https://github.com/babichmorrowc/bristol-uganda-data-week/tree/main/intro-to-r/tutorial_solutions): Solutions to the exercises in the tutorials. Please do not edit these files!
+ [`data`](https://github.com/babichmorrowc/bristol-uganda-data-week/tree/main/intro-to-r/data): Folder containing the data for the `tidyverse` tutorial

### Training #3: Introduction to probabilistic data linkage

All materials for this training are available in the folder [`intro-to-probabilistic-linkage`](https://github.com/babichmorrowc/bristol-uganda-data-week/tree/main/intro-to-probabilistic-linkage):

+ [Slides presented](https://github.com/babichmorrowc/bristol-uganda-data-week/blob/main/intro-to-probabilistic-linkage/Introduction%20to%20probabilistic%20data%20linkage.pdf)
+ Linkage tutorial and solutions: Please do not edit these files! You can make a copy of the tutorial file with your name in the file name to edit.
+ [`data`](https://github.com/babichmorrowc/bristol-uganda-data-week/tree/main/intro-to-probabilistic-linkage/data): Folder containing some practice data
